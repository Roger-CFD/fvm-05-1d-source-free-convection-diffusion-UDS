- Objective: The project solves 1D Source free,convection-diffusion problem.
- Methodology: Finite volume method is used with first order upwind discretization scheme for convective flux discretization.
- Implementation: Standalone python code is provided. The code is self-contained and includes everything required for execution, with no separate parameter files or solver files needed.
- Results: 2 plots and 1 table are provided , the table records the values of phi for a péclet number of 5 and compares to the analytical solution. The 2 plots are used to compare how effective UDS is versus Central differencing for a grid péclet number of 5.
